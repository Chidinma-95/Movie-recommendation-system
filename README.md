# Movie-recommendation-system
movie rating prediction using collaborative filtering and regularization 

## Project Overview
This project explores movie rating prediction using user and movie rating patterns.

## Objective
The goal is to predict users' movie ratings and evaluate prediction performance using Root Mean Squared Error (RMSE).

## Methods
- Exploratory data analysis
- Global, user-level, and movie-level rating averages
- Regularization of movie averages
- Validation using RMSE

## Model Evaluation
The regularized rating prediction model achieved a validation RMSE of approximately 0.8867.

## Tools
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Files
- `movie_recommendation.ipynb`: Project notebook, explanations, code, and evaluation results

## Notes
This project focuses on predicting movie ratings. A lower RMSE indicates better prediction accuracy.
